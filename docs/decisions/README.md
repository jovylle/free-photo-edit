# Architecture decision records

One file per decision that a new engineer (or agent) could not recover by reading
the code. Name them `NNNN-short-title.md`, numbered in order, never renumbered.

Copy `0000-template.md` for a new record. Keep it to one page:

- **Status** — proposed / accepted / superseded by NNNN
- **Context** — the constraint that forced a decision
- **Decision** — what we do, in one or two sentences
- **Consequences** — what becomes easy, what becomes impossible, what we accept
